# slide-brief-builder

Claude Code用のSkillです。AIカレッジ レギュラープラン特典セミナー専用に、テーマ未定の段階からセミナーの周知文（告知文）と、ClaudeDesignに渡す「ブリーフ」を、ユーザーと対話しながら一緒に作り込みます。

## できること

- テーマが決まっていない状態からの調査・テーマ決め（扱いたい道具はあるが切り口がない／ネタ切れの両パターンに対応）
- セミナーの周知文（告知文）の作成（単発・複数回シリーズどちらにも対応、複数回は新規立ち上げ／既存シリーズへの合流どちらも対応）
- 複数回シリーズの場合、シリーズ全体の構成（各回のタイトル・位置づけ・つながり）の設計
- 全体の所要時間から事務時間・実演・ワーク・講義パートの時間配分を逆算し、スライドごとの時間配分を決定（実演は事前実行のみ／当日ライブ／リハーサル+保険の3方式に対応）
- スライド1枚ごとの構成（タイトル・箇条書き・図表・スピーカーノート）作成
- ClaudeDesignで聞かれるデザイン方向性（デザインシステムのプリセット選択、またはチャットでの配色・フォント具体化・情報量・画面比率など）の事前確認
- 画像プレースホルダーを使う場合、配置場所と内容（被写体・構図・雰囲気）を提案・明記
- 保存前に周知文とスライドブリーフの整合性（タイトル・トピック・注意事項）を確認
- 最後に、ClaudeDesignへそのままコピペできる完成フォーマットを出力し、ClaudeDesignでの使い方も案内

## 使い方

1. `~/.claude/skills/` の中に `slide-brief-builder` というディレクトリを作成する
2. その中に `SKILL.md` というファイルを作成し、このリポジトリの [`SKILL.md`](./SKILL.md) の内容をそのまま貼り付ける
3. Claude Codeで `/slide-brief-builder` と入力すると呼び出せる

```
~/.claude/skills/slide-brief-builder/SKILL.md
```

## 前提

- AIカレッジ レギュラープラン特典セミナー専用のSkillです。対象者・所要時間・開催形式などの固定前提がSKILL.md冒頭に直接書き込まれています。他の用途で使う場合はこの前提部分を書き換える必要があります。
- ClaudeDesign（デザインシステム選択・詳細確認画面が出るツール）に渡すブリーフを作ることを主眼にしています。
- 生成されたスライドを画像として書き出す想定のため、画像プレースホルダーは「image-slot」のようなエディタ専用コンポーネントではなく、PPTX/Google Slidesへの書き出し後も図形として残る形式を指定する設計になっています。
